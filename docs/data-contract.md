# 资料与统计口径

`readings.cumulative` 为原始表盘累计量，不是日耗。`meters` 指定覆盖范围、换表日和前后倍率，换表日开始新累计序列，不能跨重置直接差分。`quality=missing` 和 null 对应未读表，不是零。总表含分表，不能相加当全站。`operations` 是每天独立记录的温度、营业小时和服务人数，`period` 标出改造前及报告期；不能从报告期用电训练原本应发生的基线。`adjustments` 记录停楼和新增服务，`approved` 只是业务批准，`impact_kwh=null` 表示影响尚待估计不是没有影响。预备材料有未批调整和计量缺口。资料浏览页保留原始差分核对，节能核验页按下列口径测算节省量并在不可比较时停止给出整体节能率。

## 原始表

- `readings`：1460条示例，主键为 `reading`。字段：`reading`, `meter_id`, `day`, `cumulative`, `quality`。
- `operations`：730条示例，主键为 `operation`。字段：`operation`, `site`, `day`, `temperature`, `service_hours`, `users`, `period`。
- `meters`：4条示例，主键为 `meter_id`。字段：`meter_id`, `site`, `meter`, `boundary`, `multiplier_before`, `multiplier_after`, `replacement_day`, `sub_of`。
- `adjustments`：4条示例，主键为 `adjustment`。字段：`adjustment`, `site`, `start`, `stop`, `kind`, `approved`, `impact_kwh`。

## 版本与扩展

`fixtures/data.json` 是完整导入材料，`product.json` 是当前浏览器默认选择。全量导入校验后按规范化内容指纹保存，相同内容不重复建版本。原始事实不原地修改；资料修订形成新版本。`null` 表示明确未观测，不因筛选或合计自动变为0。

`retrofit_savings/domain.py` 是领域入口，现阶段仅做字段校验及资料描述；`service.py` 连接范围选择、数据版本与服务端计算后的存档；`storage.py` 管理不可变数据和保存材料；`web/app.js` 提供浏览和导出交互。保存的材料同时包含原数据与选择，打开旧材料不重算为新数据。新增分析不限内部组织方式，但不能丢失现有原始记录核对与历史材料读取能力。统计方法、模型选择和业务结论没有预设答案。

## 节能核验口径（新增）

核验代码按职责分在四个模块，全部计算在服务端完成，页面不另算统计答案：

- `metering.py`：例行计量条件规范化。按换表日切分累计序列、应用前后倍率；换表日当天跨重置差分标记 `reset_excluded` 且不产生用量；缺测日及缺前值日标记 `missing_excluded`，绝不补零。每天的 `raw_delta`、`multiplier`、`kwh`、`status` 全量留痕，支持财务从合计钻回表盘。
- `baseline.py`：基线与反事实。日模型为 `日耗 ~ 室外温度 + 服务时长 + 使用人数 + 换表水平漂移指示`，**只用 period=baseline 的观测做 OLS 拟合**，报告期用电不参与拟合或模型选择，因此无法用报告期实际用电倒推基线。残差按 AR(1) 结构用三明治协方差修正标准误；基准期末尾留出连续时段做留时段验证（CV 限值20%）；学生化残差超 ±3 标记异常但不自动剔除；报告期逐日按基准期支撑范围判定外推，外推日占比超25%阻止整体结论，外推日的过程噪声按越界距离放大。
- `adjustments.py`：单独调整治理。倍率/重置/漂移等例行条件不进调整台账；`adjustments` 表中的停楼、新增服务逐条路由到唯一表段（停楼优先建筑分表、新增服务走总表口径），杜绝总表分表双重计算。未批准调整默认不入账但全程可见；已批准而 `impact_kwh=null` 表示影响量未估计（不是零影响），覆盖报告期即阻止整体节能率。`impact_kwh` 按登记日均影响量乘以报告期重叠天数、再乘方向（停楼为负、新增服务为正）入账。
- `verification.py`：编排与裁定。站点合计只取总表口径，分表是内部构成不与总表相加；覆盖率（基准期≥85%、报告期≥90%）、留时段验证、外推范围、异常残差、未估计调整任一不满足即 `comparable=false` 且不给出整体节能率。节省量 = 调整后反事实 − 报告期实际；95%区间合成参数误差、AR(1)过程噪声与调整误差（未给误差时按影响量25%取保守标准差）。假设结构固定为基准期窗口、留时段天数、批准覆盖、情景名称四部分，同数据+同假设的情景指纹可复现，支持两套合理假设并排复核。
