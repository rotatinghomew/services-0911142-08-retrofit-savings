# 现场复核

先在画外完成依赖或镜像准备。服务就绪检查为 `/health`，启动不下载资料。

## 资料浏览

打开首页，选择服务设施，查看分表能耗与改造事件时间线；从任一明细点开原始记录核对。保存一次当前材料，然后改动选择并重新计算，再打开刚才的记录，确认原范围仍在，最后导出。

## 节能核验

切到"节能核验"标签，选择站点并运行默认假设。先看顶部裁定：演示资料因停楼调整影响量未估计、且报告期驱动因素大范围超出基准期支撑域，会显示"停止给出整体节能率"，但表段级反事实、节省量与95%区间仍可展开核对。

在"表段钻取"中展开总表，逐日检查反事实预测、外推标记，以及 `reset_excluded`、`missing_excluded` 的计量依据；在"调整台账"中勾选托育新服务的研究员批准，改情景名称后再次运行，通过"开启并排情景复核"对照两套假设的合计、区间与阻断依据。把当前情景按名称保存到核验存档，刷新后重开确认假设与指纹冻结不变。

上述操作的设计时长为45至75秒，留出异常提示时间后不超过90秒。部署故障不隐藏也不回放旧结果。新增分析的实际结果和可操作性须在功能完成后重新验证；这里不预报尚未开发能力的演示结果，不限定显著性或结论方向。
